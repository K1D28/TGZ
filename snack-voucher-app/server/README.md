# Snack Voucher API

## Setup

1. Copy `.env.example` to `.env`.
2. Set `SUPABASE_URL` and `SUPABASE_SERVICE_ROLE_KEY`.
3. Run `npm install`.
4. Start the API with `npm run dev`.

## Endpoints

- `GET /api/health`
- `GET /api/snacks`
- `POST /api/snacks`
- `GET /api/vouchers`
- `POST /api/vouchers`
